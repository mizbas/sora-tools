プライバシーポリシー

「そらのツール箱」（https://mizbas.github.io/sora-tools/ 、以下「本サービス」）での利用者の情報の扱いについて定めます。

1. 入力した内容の保存場所

本サービスの各ツールに入力した内容（給与、医療費、サブスクの契約内容など）は、利用者の端末のブラウザ内（localStorage）にだけ保存されます。運営者のサーバーに送信されることはなく、運営者が見ることもできません。

2. Googleドライブとの連携（わが家の家計簿・サブスク管理）

  • わが家の家計簿（およびサブスク管理）の「Googleドライブで共有」を使った場合に限り、利用者の許可を得て、利用者自身のGoogleドライブに共有用のファイルを1つ作成し、そのファイルを読み書きします。
  • 使用する権限は「drive.file」（本サービスで作成したファイル、または利用者が本サービスで選んだファイルだけを扱う権限）です。ドライブ内のほかのファイルを読んだり、変更したりすることはありません。
  • ドライブのデータは、利用者の端末とGoogleのサーバーの間で直接やり取りされ、運営者のサーバーを経由しません。運営者がその内容を受け取ったり、保存したりすることはありません。
  • Googleアカウントの認証情報（アクセストークン）は、ブラウザのメモリ上で一時的に使うだけで、保存しません。
  • Google APIから受け取った情報の利用と第三者への移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • 連携はいつでも解除できます。Googleアカウントの「サードパーティ製のアプリとサービス」から本サービスへのアクセスを削除してください。ドライブに作られたファイルは、利用者が自由に削除できます。

3. 購入コード

購入コードは、ツールを開くための鍵として端末内で使うだけで、運営者に送信されることはありません。

4. アクセス解析・広告

本サービスは、アクセス解析ツールや広告を使っていません。

5. 第三者への提供

運営者は利用者の入力内容を受け取らないため、第三者に提供することもありません。
